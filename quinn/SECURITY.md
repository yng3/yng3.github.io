# Public boundary

This repository is an intentionally untrusted, purely public presentation layer. There is no QUINN runtime connectivity, remote job dispatch, wallet, API token, user session, privileged endpoint or persistent visitor data.

Review all assets, committed files, `content/dispatches.json` entries, and git history before publishing. In particular do not include QUINN private keys, root bundles, paths to private hosts or internal network addresses, command transcripts with secrets, unreleased vulnerability details, private receipts or full internal logs.

Do not connect an autonomous QUINN agent to automatic publishing. Proposed discoveries must be reviewed by a human and labeled according to evidence quality. Consider a separate approval workflow before publishing signed public attestations in a later milestone.
