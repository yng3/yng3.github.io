# ETH Kraken Bot — YNG3 project page

A public, read-only portfolio exhibition of a deterministic Python ETH futures **paper-trading research** system.

The page deliberately has no exchange credentials, network connections, telemetry, live data, login, order or wallet interface. Its animated orbit is decorative; its six-gate walkthrough is **illustrative Boolean logic**, not a market signal. The site contains no private host identifiers or account records.

## Local testing

The inline SVG/Canvas/CSS/JavaScript page was exercised in isolated Chromium at 1440×900, 820×960, 390×844, and 320×740. No page-level horizontal overflow or JavaScript errors were detected. Tab interaction, keyboard navigation, preset selection and gate switching passed. Page tests were performed using in-memory HTML because direct file or localhost navigation was blocked by the environment.

## Security and publication

The HTML has a SHA-256-based inline-script and inline-style Content Security Policy, connect-src 'none', no forms, frames or objects. There are no dependencies or paid services. The only extra resource is the existing YNG3 favicon.
